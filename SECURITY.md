# Security & Responsible Disclosure

Report suspected vulnerabilities privately to danny.wu@embedharbor.com. Include the affected repository or page, version or commit if known, impact, and safe reproduction steps. Avoid sending live credentials, customer records, private keys, or unnecessary personal information.

Do not disclose sensitive reports through public issues or pull requests. Coordinate publication with the maintainer. No response-time commitment, bounty, or supported release window is implied by this policy. Supported versions will be documented when software is released.
