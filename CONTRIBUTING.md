# Contributing

Projects are in preparation. Before substantial work, discuss a proposal with the maintainer. Keep contributions focused, explain provenance and testing, and use synthetic data that may legally be shared.

Never include secrets, customer information, internal configuration, or third-party material without redistribution rights. Submit changes through pull requests for review. Copyright ownership and license terms must be reviewed before accepting or publishing code; no project license has been selected yet.

Use the security policy for confidential vulnerability reports.
